项目地址：
https://github.com/Rachel-eee/ros2-moveit2-arm-control-tutorial/tree/main
安装`moveit2`
`sudo apt install ros-$ROS_DISTRO-rmw-cyclonedds-cpp`

配置机械臂
ros2 launch moveit_setup_assistant setup_assistant.launch.py 

运行moveit
ros2 launch moveit_config demo.launch.py

创建启动包
ros2 pkg create robot_bringup --build-type ament_cmake --license Apache-2.0

- 启动规划

```bash
#两个终端分别先后启动
ros2 launch robot_bringup robot_bringup.launch.py 
ros2 launch arm_control arm_control.launch.py 
```

- 规划成功关键日志
Planning request complete!
Execute request success!
process has finished cleanly

规划多个位姿不成功时考虑更改初始位姿
先在sw中拖到相近位姿
使用display.launch.py调整关节位姿并更改joint/rpy,依据axis的1
下一步接入相机
---

已接入相机
如果出现gzserver启动失败
```bash
#查看残留进程
ps -ef | grep -E '[g]zserver|[g]zclient'
ss -ltnp | grep 11345
#终止对应pid
kill <gzserver_pid>
```

启动
```bash
#同时启动control
ros2 launch robot_bringup gazebo_bringup.launch.py \
  start_arm_control:=true

#单独启动control
ros2 launch arm_control arm_control.launch.py ust:=true

```
